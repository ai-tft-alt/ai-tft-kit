# 공문 한 장 요약 (브리핑)

## 입력
- 공문·안내문 텍스트 (한글 파일이면 `tft-hwp-read`로 먼저 읽는다)

## 출력: `<원본이름>_요약.md` (같은 폴더)

```markdown
# [요약] <공문 제목>
- 문서: <발신 부서> <문서번호> (<시행일>)
- 한 줄 요약: <누가 / 무엇을 / 언제까지>

## 해야 할 일
| 할 일 | 기한 | 담당(제안) |
|---|---|---|

## 핵심 내용
- 일시 · 장소 · 대상 · 방법 등 (원문 표현 그대로)

## 확인할 점
- 원문에서 모호하거나 빠진 정보
```

## 규칙
- 날짜·숫자·연락처는 원문 그대로 옮긴다. 추측하지 않는다.
- "해야 할 일"은 기한이 빠른 순서로.
- 원문에 없는 내용은 "확인할 점"에만 쓴다.
- 요약을 메일·메시지로 보내 달라는 요청이 이어지면, 보내기 전에 **초안**으로 만들고 사용자의 확인을 받는다.
