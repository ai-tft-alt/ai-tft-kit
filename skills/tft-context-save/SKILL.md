# 이어서 일하기: 중간 저장 (Context Writing)

## 언제
- 컨텍스트 사용률이 30~40%를 넘었을 때 (상태줄 노랑)
- 퇴근 전, 다른 작업으로 넘어가기 전

## 하는 일
프로젝트 폴더의 `context.md`를 새로 쓴다(있으면 덮어씀).

```markdown
# 작업 이어가기 (<날짜 시간>)
## 목표
## 지금까지 한 일 (파일 경로 포함)
## 남은 일 (다음에 바로 할 것부터)
## 결정한 것 · 이유
## 주의할 점 (막혔던 곳, 하지 말아야 할 것)
## 다시 시작할 때 첫 프롬프트
"@context.md 읽고 '남은 일' 첫 번째부터 이어서 해줘"
```

## 규칙
- 30줄 안팎으로 짧게. 코드 전체를 붙이지 말고 파일 경로만.
- 저장 후 사용자에게 "/clear 후 `@context.md 읽고 이어서 해줘`" 를 안내한다.
