# 결정 기록 (Decision Writing)

코드와 문서에는 "무엇(What)"만 남고 "왜(Why)"는 사라집니다. 끝난 작업마다 이유를 남겨, 나중에 다른 사람(또는 다음 Claude 세션)이 읽게 합니다.

## 하는 일
`decisions/<YYYY-MM-DD>-<짧은-제목>.md` 를 새로 만든다.

```markdown
# <제목>
- 날짜: / 관련 파일:
## 배경 (무엇이 문제였나)
## 결정 (무엇을 했나)
## 이유 (다른 방법 대신 이것을 고른 까닭)
## 결과 · 확인 방법
## 다음에 참고할 점
```

## 규칙
- 한 파일에 한 결정. 20줄 안팎.
- `context.md`(진행 중)와 달리 decisions/는 **끝난 일**만 기록한다.
- CLAUDE.md에 "중요한 결정은 decisions/ 참고" 한 줄이 없으면 추가를 제안한다.
