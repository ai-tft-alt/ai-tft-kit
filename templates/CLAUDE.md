# <프로젝트 이름>

## 목적
- 이 폴더는 <업무 이름>을 자동화합니다. (PRD.md 참고)

## 폴더
- data/ : 입력 파일 (원본은 고치지 않음)
- output/ : 결과물
- decisions/ : 끝난 작업의 결정 기록 (tft-decision-log)
- 하위 폴더에 CLAUDE.md가 있으면 그 폴더 작업 때 함께 읽을 것 (계층형)

## 규칙
- 개인정보(주민번호·전화번호)는 결과물에 넣지 않는다.
- 메일·메시지는 초안까지만 만들고 사람의 확인을 받는다.
- 중간 저장은 context.md (tft-context-save), 완료 기록은 decisions/ (tft-decision-log).
- 완료 선언 전 검증 스크립트가 있으면 반드시 실행한다.
